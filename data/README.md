# Track B data

`btc_sample.csv` is a **synthetic** BTC-like 1-minute OHLCV path
generated by `camase.trackb.synthetic_btc` (seed=7, n=1500).

Header: `timestamp,open,high,low,close,volume`

SHA-256: see `btc_sample.csv.sha256`.

Replace this file with a real Binance (or other) dump using the same
header before any paper sentence that says “BTC/USDT”. Keep the sample
if you only need a loader smoke test.
